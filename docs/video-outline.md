# Demonstration video outline

The assignment requires a **brief video showing the code in action** and
highlighting accomplishments. It does not specify an exact duration in the
supplied text. Check Canvas for any additional constraint.

Only record verified execution. A slide deck, source-code scroll or simulated
progress animation is not a substitute for showing the actual software.

Suggested sequence:

1. State the single research question and show the repository/site and tested
   version. Explain the actual contribution without claiming to invent EnCodec.
2. In MATLAB Online, run `run_project_tests` and show discovered/passed counts.
   Explain Experiment 0 and why near-perfect unchanged reconstruction validates
   the analysis rather than answering the codec question.
3. Show one prepared original and its real Opus/EnCodec 6/12 kb/s files/manifest.
   Identify the common input, measured bitrate and actual timing scope. Long
   preparation can be edited for brevity, with the edit labelled honestly.
4. Run `run_diagnostic` on a real speech example. Open the generated report,
   waveform/error plots and three-resolution spectrograms. Explain one actual
   transient, harmonic or fricative observation, including ambiguity if present.
5. Show verified aggregate findings if available, one limitation and what the
   project did/did not establish. Link to code, report and reproduction steps.

If only the synthetic demo works, label it clearly and state the remaining
research gap. Do not present synthetic input as recorded speech or show invented
results to fill an unfinished section.
